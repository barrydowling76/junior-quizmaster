# Junior Quizmaster — voice prototype

A daily five-question kids' quiz hosted by Professor Quizzard. Children answer out loud; an answer only counts once they say "The answer is…". After the quiz they're offered a fun fact.

- Single static page (`index.html`), no build step. Served by GitHub Pages.
- Voice in: Web Speech API (Chrome on Android/desktop, Safari on iPhone/iPad). Voice out: the device's speech voices.
- Test version: quizzers and scores are saved on the device only. Parent logins and the class leaderboard come in the full app.
